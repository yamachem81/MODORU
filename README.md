# MODORU

**Find Your Way Back.**

MODORU means "to return" in Japanese.

The name has three meanings:

1. Return to a red pin on the map.
2. Return to your favorite places.
3. Return home safely.

## Features

- Save multiple places with GPS.
- Show or hide individual map pins.
- Rename or delete saved places.
- Tap a place to return to it on the map.
- Check the distance to your destination.

Built with HTML, JavaScript, Leaflet, and GSI Japan maps.
